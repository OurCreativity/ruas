# Sample Graph Exports

This directory holds sample visual and machine-readable graph exports generated by `ruas export`.

## Available Formats

1. **`graph.html`** — Interactive offline visualizer powered by Cytoscape.js with Bayesian edge probability coloring, node filtering, and search.
2. **`graph.mmd`** — Mermaid markdown graph definition for embedding directly into GitHub PRs, markdown wikis, and documentation.
3. **`graph.dot`** — Graphviz DOT specification suitable for compilation into SVG or PNG via `dot -Tsvg graph.dot -o graph.svg`.
4. **`graph.json`** — Complete machine-readable graph topology containing nodes, edges, Bayesian confidence levels, and token metadata.

## Generating Graph Exports

To generate graph exports for any repository:
```bash
# Standalone Interactive HTML
ruas export . --html docs/graph.html

# Mermaid Markdown Diagram
ruas export . --mermaid docs/graph.mmd

# Graphviz DOT
ruas export . --dot docs/graph.dot

# Raw JSON
ruas export . --json docs/graph.json
```
