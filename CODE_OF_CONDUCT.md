# Code of Conduct

This project follows the [Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good faith, give constructive feedback, and no harassment
or discrimination of any kind. Maintainers may remove comments, commits or contributors that
violate this. Report concerns privately to kou.real@outlook.com.
